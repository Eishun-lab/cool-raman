## 🏛️ ブランドコンセプト（Brand Concept）
「**한（韓 / ひとつ）**」＋「**모아（集める・結集する）**」

入門ハングルからTOPIK最上級、検定模擬試験、文法大辞典まで、韓国語学習に必要なすべてを1つの場所に美しく集約したオールインワン・プラットフォームです。

---

## ✨ 主な機能（Key Features）

### 1. 🎓 TOPIK ＆ ハングル検定 4大本格模擬試験
- **TOPIK I 模擬試験（初級）**: 1〜2級判定 / 20問 100点 / 制限時間20分
- **TOPIK II 模擬試験（中上級）**: 3〜6級判定 / 20問 100点 / 制限時間25分
- **ハングル検定 基礎模擬試験**: 4〜5級判定 / 20問 100点 / 制限時間18分
- **ハングル検定 応用模擬試験**: 3〜準2級判定 / 20問 100点 / 制限時間22分
- **特徴**: カウントダウンタイマー、ネイティブリスニング音声、問題パレット、合否判定レポート、教科書・辞書への復習リンク。

### 2. 📖 完全攻略 体系教科書（全40課 / 全5ステージ）
- **第1章（第1〜10課）**: ハングルと文法・助詞の土台（入門）
- **第2章（第11〜20課）**: 日常表現の拡大と重要活用（初級前半）
- **第3章（第21〜30課）**: 複文・理由・義務・連体形（初級後半）
- **第4章（第31〜35課）**: 伝聞・使役受動・仮定・婉曲（中級実戦）
- **第5章（第36〜40課）**: 推量・動作状態・感情終結語尾・格調論述（中上級完成）

### 3. 🔖 文法逆引き大辞典（全250項目 / 全11ブロック）
- 初級の基本願望・意志から、TOPIK II 6級レベルの格調高い論述文法まで完全網羅。
- 活用ルール、豊富な例文、注意点、関連表現のクロスリファレンス。

### 4. 🔢 数字完全攻略マスター
- 漢数詞（1〜1億超）と固有数詞（1〜99）の完全対応表。
- 助数詞（個、匹、名、歳など）、時刻・日付の使い分けガイド。

### 5. 💡 8大リファレンス集
- 必修単語 1,050語 ＋ オノマトペ・擬音語擬態語 50選
- 似ていて紛らわしい表現 90選
- よくある疑問 Q&A 47選
- キラーフレーズ 110選（K-POP推し活・ソウル旅行クリニックカフェ含む）
- 日常実践チャンク 60選
- 若者スラング・新造語 60選
- 四字熟語 40選 ＆ 身体慣用句・ことわざ 100選
- 高級論述・統計表現 40選
